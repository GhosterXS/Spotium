Spotium

A Spotify-style music client for Android, built with Jetpack Compose.

Spotium connects to your real Spotify account and aims to mirror the everyday Spotify experience on Android — playlists, lyrics, recommendations and library — with extra themes and personalisation.



Not open source. This repository is used for releases and updates only (APK distribution). Source code is private.

Features





🎵 Playlists — browse, play, add/remove tracks, create playlists, synced with your Spotify account



📝 Lyrics — synced lyrics with live preview on the player and a full-screen view (optional Beautiful Lyrics style)



📻 Recommendations — queue can continue with Spotify-style radio / up next



❤️ Liked songs, followed artists, listening history and downloads



🎨 Themes — starry sky and other customisable backgrounds



🔄 In-app update prompts when a new APK is published on this repo

Releases

Install APKs from the Releases page.
File names should follow: spotium-vX.Y.apk (example: spotium-v1.2.apk) so the app can detect newer versions.
